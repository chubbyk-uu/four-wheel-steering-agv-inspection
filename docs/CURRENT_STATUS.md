## 下一步顺序

**当前主目标是100×10 m全区域稳定采集。通过实施计划第6节的验收门槛前，不推进正式拼接/TIFF阶段。** 小矩形、单道高速演示或一次ACQUIRED均不能替代该验收。

1. 先复核100×10 m全宽道路及非采集缓冲区的空间、磁盘、显存/内存预算，再生成资产；GZ/RViz低清显示、OptiX高清分块采样，不能仅将20 m场景的终点参数改为100 m。
2. 在完整区域以1 m行距低速验证首末/两侧覆盖、加减速、横移和180°换行；修复转场定位不确定度、覆盖判定和补扫合并问题，不通过缩小协方差掩盖缺口。
3. 在足够运动空间内逐档提高至10 km/h，检查跨块采图连续性、行标签、队列、实际运动、实时率和资源增长；独立11 kHz吞吐另测。
4. 系统回归不同阶段的暂停/恢复、取消、故障停车、重复任务和GUI/RViz操作；关闭已知影响采集可靠性的高优先级问题，完成多次全区域运行及补扫闭环。
5. 完成上述验收后，才重做当前光学/条光正式离线标定并进入条带运动补偿、跨轨配准、拼接和TIFF。已有离线诊断工具保留，不将其作为近期开发主线。

验收范围、重复次数与缺陷关闭条件统一见[实施计划第6节](MISSION_IMPLEMENTATION_PLAN.md)。自主绕障仍是后续独立扩展，C8点云存在不等于具备避障。

当前不加入支架振动；坡面/可通过高差为后续独立验证，不能默认已有平地结果适用。具体交付条件见[实施计划](MISSION_IMPLEMENTATION_PLAN.md)。
