### 已完成的前置试验：固定安装残差（历史顺序）

本节保留前置试验依据；后续执行以“当前条带处理方案”和“随机振动敏感性试验”为准。

先做固定相机安装标定残差，不增加支架振动、受力挠曲或六自由度随机运动。保留现有车体/悬挂动力学和刚性相机安装。实际成像使用T_true；只修改算法使用的T_hat，一次试验内固定。残差不是每帧位置噪声，也不改变原图。相机真值位姿只能用于独立评分，不能进入生产重投影。

第一步建立零相机残差对照与逐轴、有正负号的敏感性配置：车体X向前、Y向左、Z向上，平移1/3/5 mm；然后单独测绕这些轴的0.05/0.10/0.20°角度残差。不先混合多个轴，不修改GNSS/IMU/轮组噪声或其它外参。角度为旋转向量分量；扰动以相机光心为原点，配置文件仍按现有光学坐标系的右乘约定存储，工具负责坐标换算。这些档位用于敏感性试验，不是设备实测精度。

先核验标定归档/估计标签确实变化、物理模型及真值输入不变；再做当前20 mm标定、短程双道连续条带重投影和匹配。固定残差的影响解释清楚后，才另行讨论支架振动。零相机残差对照仍保留正常定位噪声，不应称为全系统零噪声。

配置生成（现已实现，不覆盖现行默认参数）：

```bash
python3 tools/generate_camera_residual_trials.py --output local_data/camera_residual_trials_v1
```

生成37份完整定位配置：1份baseline、18份平移、18份角度。目录必须不存在；`manifest.json`记录档位、配置摘要和源文件摘要。可用`--base`指定另一份测量配置，除相机两个残差键外保持原值。先比较`baseline.yaml`与`translation_mm_x_plus_3.yaml`；后续再比较其它轴和角度，不能将所有档位都作为默认必跑任务。

启动时通过现有`localization_config:=/absolute/path/to/trial.yaml`传入，同时启用`localization:=true`；任务验证工具对应参数为`--localization-config`。工具只生成配置，不启动或移动车辆。档位按相机光心处的固定标定误差解释，不是物理支架绕连接点振动。

目前验证了所有档位经过生产标定归档函数后的方向、幅值、独立标定ID和其它传感器外参不变；生产估计标签在0/180°车头朝向下正确传播固定位置残差，并忽略被替换的原始真值位姿。随后完成20 mm固定平面标定及零相机残差配置下的GUI双道采集，对同一批原图做+3 mm车体X外参受控重放；结果与限制见[离线处理](../../OFFLINE_PROCESSING.md)。尚未完成跨道匹配或跑完37个档位，不能将接口/重投影测试称作拼接精度验收。

### 基线条带标线波动归因（2026-09-14）

`strip_projection_baseline/comparison.png`来自融合导航XYZ+姿态、离线实测光学映射与平场补偿，对每行投影到z=0后栅格化；没有特征匹配或条带优化，未读取真值位姿。这次相机安装残差及其它配置外参残差均为零，没有支架振动注入，传感器噪声/延迟开启。GNSS每轴σ为25/25/40 mm，10 Hz；测量时间戳保留，global EKF启用`smooth_lagged_data`和当前时刻预测，不能把50 ms GNSS到达延迟直接等同于50 ms图像错位。

事后诊断单独读取真值（不反馈给投影器）：每道X=6–9 m内各10个真值标签，选择世界Y=0.15 m的直标线射线，对照融合导航的相机光心与朝向。第一/第二道横向投影误差标准差约5.82/8.03 mm；其中单独替换光心Y的影响约5.48/6.88 mm，替换光心Z约6.10/4.06 mm，固定光心只替换完整朝向约0.13/1.40 mm。分量相关，不能相加或平方和当成占比。光心Y也包含姿态经前置相机杠杆臂引入的误差，不能误称为仅GNSS横向噪声。

融合机体高度误差标准差约9.9 mm。三维射线投影的横向距离随光心高度缩放，所以高度噪声是本图波动的重要来源；不能仅归因于车体左右摆动。真实相机横向位置在这些标签上确有约11/22 mm峰峰变化，但准确位姿投影应补偿这种运动；它不应与定位误差作为独立项直接相加。真实俯仰变化约0.004–0.005°峰峰，当前稀疏记录不支持“强烈高频支架振动”的结论。

全图按32行取中值检测两条标线中心：第一道中心波动标准差约5.4–7.5 mm，第二道约8.4–9.4 mm，5%–95%跨度约17–27 mm。光学拟合残差、固定名义高度的成像假设、稀疏行时间插值与栅格化仍在图像中，未由上述稀疏真值分解完全覆盖。标签间约1024行，仅凭现有记录不能量化其间时间插值误差，也不能给GNSS/IMU/轮速噪声与延迟分别分配百分比。需固定轨迹/传感器随机序列做受控重放；不要通过重新驾车导致轨迹改变的简单开关实验冒充严格分解。详见[数值记录](../../../results/strip_wave_components.json)。
