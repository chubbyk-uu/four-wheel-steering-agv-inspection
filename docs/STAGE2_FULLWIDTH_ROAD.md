# 20×10 m 全宽道路与相邻扫描试验

> 历史实验记录：本文参数、性能和“当前/默认”描述属于当时版本，不作为新版验收。现行550 kg、20 mm/4K/1.5 m、1 m轨迹间距、11 kHz目标见[当前模型基线](LARGE_AGV_REBUILD.md)。历史命令须按现行配置调整，旧16 mm标定不可用于新版；大体积实验资产可能已清理，复现需重新生成。

先验证20 m短路段的全10 m宽高精度材质，再扩展100 m。沿用Concrete047A颜色＋法线、统一粗糙度0.60和用户确认的AI分叉裂缝。默认原图4096×4096 Mono8线性；校正、拼接与显示TIFF在离线阶段处理。

## 资产与预算

生成命令：

```bash
python3 tools/generate_streaming_road.py --output assets/road/baked_fullwidth_20m_v1 --length 20 --full-width
```

高精度范围x=[−1.024,21.504]、y=[−6.144,6.144] m，包含名义20×10 m巡检区域外的视野余量。0.25 mm/纹素，2048核心＋每边2像素真实邻域边框，共44×24=1056块，颜色R8＋法线RG8，无损磁盘纹素约13.34 GB。32槽纹素负载仍约385.5 MiB，不含纹理对象、暂存、BVH、输出及GUI占用。GZ用同源约4 mm/纹素概览。

5×5 m板块，纵向中缝位于两条黄实线之间，白线位于y=±4.5 m。4个裂缝实例复用同一AI源，只有位置与镜像变化；尚不代表足够多样的缺陷检测训练集。裂缝0.8–2.0 mm名义宽度，沟槽最多2 mm深；板缝8 mm宽、3 mm深。材质与成像几何由同一轮廓生成。

GZ视觉和OptiX共用精细网格。8个几何分区分别声明2三角形水平碰撞代理，共16碰撞三角形；逐区检查深度≤3 mm、受影响投影面积≤1%、覆盖边界相同。该政策仅适用于稀疏细沟槽，不能用于后续明显凹坑、凸起或台阶。

## 验证方法

独立吞吐试验使用12图块一程的夹具路径，往返于相机x=2..16.4 m，96图块持续约35 s，验证11 kHz、落盘、独立ROS接收、瓦片淘汰和缓存缺失。夹具瞬时反向只用于压力测试，不代表车辆运动。

实际相邻轨迹试验使用带仿真时间戳的车体TwistStamped和现有制动/对轮控制器。轮子编码器局部积分控制前进10 m、停车横移0.9 m、对轮后倒车。换行关闭采集，同一轨迹不重复末行，轨迹之间名义侧向重叠0.3 m。仿真真值仅记录作评估，不参与运动控制。

这一步不是RTK＋IMU融合定位、自动覆盖规划或拼接验收。编码器试验器只适用于本次平地短程，无打滑校正；GUI低速功能验证也不能替代独立11 kHz吞吐试验。

## 结果

全宽烘焙完成，用时818 s，1,522,958个成像三角形；全部1056对颜色/法线瓦片相邻边框最大差为0 DN。8项辅助测试通过。

独立夹具原图链路持续35.109 s，达到11,199.91行/s；每图4096行，96图全部fsync落盘并通过独立ROS逐字节核验。固定32槽，948次加载、924次淘汰，预热后必需瓦片缺失为0。最大批次10.41 ms（预算22.86 ms），最大图块接收间隔381.60 ms（预算548.57 ms）。显式设备分配约555.4 MiB，其中纹素负载约385.5 MiB；不是包含驱动、GUI及其它进程的总显存峰值。active链路约27.02 kHz，只是当前场景处理能力，不提高11 kHz目标。OS文件缓存可能已热，冷磁盘加载未单独验收。

GUI＋RViz实际相邻扫描通过：前进34,128行、倒车34,125行，各9图，其中最后一图为尾块；原图与元数据均与归档一致。横移目标0.9 m，评估实测0.898767 m，名义视野的侧向重叠约0.301233 m。换行无出图，各轨迹全局行号与编码器距离连续，最终HOLD。控制使用轮子编码器，不使用真值。扫描速度0.5 m/s，这是运动与归档功能测试，不是11 kHz实时性能测试。


道路边缘短时整车测试：出生x=0.5 m，相机沿y=±4.45 m扫描，畸变后视野越过名义y=±5 m边界，仍在加宽后的真实材质/几何范围内。两次均通过连续性、ROS字节一致和零必需瓦片缺失检查，最后HOLD。

| 测试 | 实时率 | 采集行数 | 采样队列峰值 |
|---|---:|---:|---:|
| +4.45 m侧，GUI＋RViz | 1.00015 | 40,588 | 67行 |
| −4.45 m侧，无GUI | 1.00021 | 40,531 | 57行 |

指令10 km/h，测量窗口4.32 s中仍包含加速末段，实际平均约9.89 km/h；不是长时间稳态满速验收。GUI的RViz同步TF错误为0，轮心最大单步z变化约6.4 µm，未发现先前毫米沟槽碰撞导致的明显抖动。两次位置不同，表格不能解释为严格同轨迹GUI开销对照。采样队列峰值和实时率也不能代替GUI帧时间的完整分布测量。

数据汇总见[机器可读结果](../results/stage2_fullwidth_road.json)。用户已调整顺序：下一步先完成矩形规划、融合定位、time任务控制与RViz任务交互，完整任务采集通过后再做离线拼接和TIFF，见[矩形任务设计](RECTANGLE_MISSION_PLAN.md)。已有双轨档案保留作辅助回归。整条100 m的高清磁盘占用会随面积增加，GPU纹理缓存仍固定容量，但几何和GUI资源必须重新实测。


## 运行与复现

先按README设置ROS、构建和OptiX运行库。WSL需通过项目的隔离运行库包装器执行；原生Linux按README配置驱动运行库即可。以下命令应在已加载项目环境的shell内运行：

```bash
python3 tools/benchmark_optix_stream.py --scene assets/road/baked_fullwidth_20m_v1/manifest.json --output /tmp/fullwidth_stream_new --blocks 96 --pass-blocks 12 --track-y 2.5 --rate 11200
python3 tools/validate_adjacent_scans.py --scene assets/road/baked_fullwidth_20m_v1/manifest.json --gui --rviz
python3 tools/validate_rendered_linescan.py --backend optix --scene "$PWD/assets/road/baked_fullwidth_20m_v1/manifest.json" --gui --rviz --spawn-x 0.5 --spawn-y 4.45 --speed 2.777777777777778 --warmup 3 --distance 12
```

仅查看场景：

```bash
ros2 launch agv_bringup sim.launch.py linescan:=true linescan_backend:=optix scene_manifest:="$PWD/assets/road/baked_fullwidth_20m_v1/manifest.json" spawn_x:=2 spawn_y:=2.05 rviz:=true
```

测试器自动发零速度、确认停车并关闭它启动的GUI/仿真。手动启动场景则由用户控制。全宽场景使用显式参数选择，不改变默认世界。
