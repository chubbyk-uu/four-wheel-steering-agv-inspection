# 掉头对轮后过早开采触发航向保护

2026-09-15。本问题是开采准入遗漏了实际车身航向检查；不是180°目标角算错，也不是相机支架振动被误当成车身航向。修复保持软悬挂、起伏路面及原0.05 rad采集保护，不增加后退或额外原地转向。

## 根因与证据

原来的次序：完成掉头、停车判定合格 → 用低速探测指令将四轮恢复直行 → 底盘报告DRIVE → 立即打开相机。

DRIVE只检查轮角、轮速和转向跟踪，并不保证车身仍朝着对轮前的方向。真实物理求解中，对轮动作与轮胎接触、车体动力学耦合，轮子不主动驱动也可能让车身偏转。上层在对轮期间冻结探测指令；恢复DRIVE后才开始正常航向反馈。旧逻辑没有给这个反馈恢复的时间。

保存的刚性相机、zero定位试验`mount_flex_probe_v1/rigid_zero`：

- 180°旋转结束，实际yaw约−179.57°，并非掉头少转4°。
- 第二道直行对轮51.441–53.601 s，实际车身yaw变化−4.253°，位置变化约厘米量级。
- 四轮从约[−54.9°,−128.5°,−123.2°,−53.4°]回到约[0°,−180°,−180°,0°]；记录的是实际关节反馈，不是期望角。
- DRIVE第一帧参考航向误差0.074255 rad；16 ms后开采确认，随即触发0.05 rad保护。控制反馈尚未恢复，保护本身正确。
- 600档支架、normal定位的另一次失败，同一阶段实际yaw变化−2.921°，开采误差约0.052 rad。刚性/zero也失败，排除了“必须有支架柔性或定位噪声才触发”的解释。

平地、新软悬挂的运动对照，两道完成；第二道对轮yaw变化仅−0.0011°，但第一道对轮仍有1.688°偏转。说明平地也可能发生对轮偏转，粗糙接触会改变响应；独立任务的轮角分支与接触状态并非完全相同，不能把各次偏差比值当作悬挂刚度的确定传递函数。没有接触力分解，不能进一步把全部偏差归给某一轮或某一个接触求解项。

恢复旧65000 N/m、2800 N·s/m及旧预载，关闭相机柔性，在同一起伏试片zero定位下复测：第二道对轮仍偏转−3.114°，DRIVE初始误差0.05436 rad。**软悬挂不是触发此问题的必要条件**，不能靠调硬悬挂修复开采逻辑。该对照使用相同几何和控制参数，只覆盖弹簧/阻尼/预载，开启新准入规则后完整双道通过。

## 修复

在已有前导段按原梯形/三角形时间轨迹加速并使用融合定位闭环；只有DRIVE且实际参考航向误差进入`min(heading_tolerance_rad, 0.5*max_capture_heading_error_rad)`才打开快门，当前为0.025 rad。

快门一旦打开，继续保持原来的0.05 rad保护；不因重新超出0.025 rad而关闭/拆开半帧。普通暂停仍保留未满帧。若到ROI入口尚未开采，原有`CAPTURE_NOT_ACTIVE_AT_REGION`仍使任务失败，不允许略过区域再声称覆盖成功。前导不足的任务仍可能明确失败，此修复没有保证所有低速短前导都能消化任意对轮偏差。

未改速度曲线、反馈增益、死区、保护门限、悬挂、轮胎摩擦或相机图像。不重置参考航向去接受偏差。代价是舍弃部分ROI外的前导图像，正常任务时间不因此增加等待段；尚未收敛时不会记录不合格的前导线。

## 验证与边界

首次修复实跑：同一20 m、10 cm网格、±3 mm试片，X=8..12 m双道、1 m间距，请求10 km/h；默认150 N·m/rad支架、normal定位、GUI＋RViz＋OptiX。

第二道对轮仍产生−3.956°实际yaw变化；DRIVE开始误差0.07008 rad，经2.347 s前导反馈后开采，开采后最大误差0.02497 rad。实际投影采集起点在ROI前2.749 m，两道各24470/19530行，连续ROI及ROS/原图一致检查通过，最终ACQUIRED/HOLD，无PASS后退指令。

实际查看11张原图缩略图：路面纹理和标识连续可见，无明显空白缺线；尾图保持实际行数比例。GUI/RViz参与联合运行，未重新进行宿主窗口鼠标操作或逐部件人工显示验收，此次没有修改GUI/TF。

回归锁定：对轮产生正/负航向偏差时不开采、前导纠偏后开采、开采后越过较小准入容差不拆半帧、超过原保护值仍FAULT、未恢复就到ROI入口必须FAULT。数值由`tools/analyze_heading_recovery.py`从实际真值、逐轮关节和任务记录提取；本轮数据位于忽略的`local_data/heading_probe_*`。

此项为短双道恢复验证，不替代新悬挂/支架的100 m全区复验。

### 暂停验证器的独立误判

第二轮GUI复测任务本身已ACQUIRED/HOLD，但工具报`pause split a full frame`。检查实际归档：暂停时未输出半帧；同一块跨过停车及恢复，最后在正常道尾以`capture_toggle`输出1715行。短道10 km/h制动约走4 m，暂停后剩余行数不足补满4096，这是合法尾图，不是暂停拆帧。

验证器原先无条件要求跨暂停的块4096行；改为允许正常结束时输出至少`min_tail_rows`的尾图。保留暂停期间图片数量不变、跨停车相邻global_line连续、至少2秒停顿、两道ROI连续及原图/ROS一致检查；拒绝过短尾图和异常结束。新增6个完整块/尾图接受拒绝用例。此处只修验收判据，未修改采集插件。

### 复现方式

使用`tools/validate_rectangle_execution.py`，请求保存在`local_data/mount_flex_probe_v1/request.yaml`（X=8..12、Y=−1.9..0.1、间距1 m、10 km/h）。`--scene local_data/rough_markings_3mm_v2/manifest.json --profile normal --gui`为现行联合场景，`--pause-once --inject-track 1`在第二道测试暂停。经项目OptiX和Mesa包装启动，完整输出重定向日志。

旧刚度对照用`--suspension-config`指定只包含弹簧/阻尼/预载的YAML；工具归档合并后的platform配置，只覆盖物理模型，不允许该选项修改几何或控制能力。使用65000、2800、三个preload均−0.016，并用`--camera-config`关闭支架柔性、`--profile zero`。不带`--scene`为flat.sdf运动对照，不冒充成像验收。

最终重复验证：默认150档、normal定位、GUI/RViz第二次完整双道并在第二道暂停/恢复通过，最终ACQUIRED/HOLD；两道24576/20480行，ROI连续、原图/ROS相同，无PASS后退。第二道对轮偏转−3.439°，前导2.159 s后开采，开采最大航向误差0.02344 rad；一张4096行图跨过3.688秒停顿，暂停期间无半帧输出。此前1715行尾图也独立核对：跨停车间隙3.852秒，两侧global_line恰好相邻；尾图判据修复并未隐藏断线。

现行任务包colcon共170项，零错误/失败/跳过。默认配置两次GUI双道通过、旧硬悬挂一次无头双道通过；各次原始记录及逐轮角度保留。数值见[报告](../../results/post_turn_heading.json)，使用`analyze_heading_recovery.py --run 运行目录`可重复指定多个目录生成同一报告。所有演示已结束并确认HOLD。
