# 融合定位首版误差与时序参数

2026-09-08。用户确定GNSS RTK 10 Hz，FIX水平可信精度2–3 cm、垂直3–5 cm；其余采用下表首版仿真设计。本文件记录参数约定，传感器和EKF尚未接入当前launch，不能据此宣称噪声已经生效。参数不是指定真机设备的性能规格。

## 精度口径与GNSS

首版明确把范围中值解释为每轴一倍标准差：ENU的E/N各σ=0.025 m，U轴σ=0.040 m；高斯白噪声独立采样，不裁剪位置噪声到±σ。水平二维RMS约3.54 cm，不把“每轴2.5 cm”宣称为二维95%半径2.5 cm。用户后续提供设备CEP/RMS/95%定义时再换算。

- FIX频率10 Hz。位置测量协方差对角为[0.000625,0.000625,0.0016] m²。
- 固定传输延时50 ms，加σ=5 ms的高斯抖动（抖动限制±15 ms），独立于测量噪声。
- 正常通信基线丢包0%，时间戳固定偏差0，时间戳抖动0。零外参误差只用于理想对照；第二步必须加入安装/标定残差试验，见下节，不能把真实杆臂已建模等同于外参已准确标定。
- `header.stamp`是原测量时刻；延迟仅改变消息到达时间，不伪造新测量。RTK FIX状态另行明确报告，不把NavSatStatus普通有效定位标志当作完整FIX/FLOAT状态。
- 后续相关慢漂、多路径、FLOAT和失锁独立加入压力场景，不给正常基线叠加未量化位置偏置后仍声称满足2–3 cm。

[NavSatFix官方定义](https://docs.ros.org/en/jazzy/p/sensor_msgs/msg/NavSatFix.html)规定位置协方差为ENU、单位m²，时间戳对应测量时刻。

## IMU

| 项目 | 首版值 | 说明 |
|---|---:|---|
| 输出频率 | 100 Hz | 与爬壁项目一致 |
| 角速度白噪声 | 每轴σ=0.0002 rad/s | 每个样本标准差，不是噪声密度 |
| 加速度白噪声 | 每轴σ=0.017 m/s² | 同上，沿用爬壁量级 |
| 陀螺仪固定零偏 | 每轴跨运行σ=0.0001 rad/s | 固定种子抽一次，本次运行恒定 |
| 加速度固定零偏 | 每轴跨运行σ=0.010 m/s² | 同上 |
| 输出延时 | 5 ms＋σ=1 ms抖动 | 抖动限制±3 ms，保留测量时间戳 |
| 丢包 | 0% | 正常基线 |

传感器协方差初始包含白噪声与零偏先验方差：角速度每轴5e-8 (rad/s)²，加速度每轴0.000389 (m/s²)²。固定零偏是时间相关误差，简单增加R不能完整表达它；robot_localization通用状态不直接估计独立IMU零偏，需通过静止校准/外部预处理和实测一致性验证，不能宣称EKF自动消除零偏。慢变零偏及随机游走后续单独压力测试。

首版融合角速度；加速度先发布归档，完成重力补偿、安装旋转、零偏校准和加减速回归后再决定融合。六轴IMU不直接提供真值绝对yaw加噪声的“姿态测量”。若后续加入AHRS，必须声明航向来源及姿态滤波处理，不能把从同一原始IMU生成的观测当独立来源重复赋高权重。

## 四轮里程计

| 项目 | 首版值 | 说明 |
|---|---:|---|
| 输出频率 | 100 Hz | vx、vy、wz由四组驱动/转向反馈解算 |
| 驱动编码器 | 每轮一圈16384计数 | 指计入减速比/正交解码后的有效轮端计数；暂定仿真参数 |
| 转向反馈白噪声 | 每轮σ=0.03° | 实际反馈值加噪声 |
| 轮径标定残差 | 每轮σ=0.1% | 独立固定种子抽样，本次运行不变 |
| 输出延时 | 10 ms＋σ=2 ms抖动 | 抖动限制±6 ms |
| 速度协方差初值 | vx/vy各σ=0.02 m/s；wz σ=0.01 rad/s | 初始信任下限，不是再次加到速度上的白噪声 |

0.20 m轮半径时每计数约0.07670 mm。量化保留完整累计角度，不能每步独立四舍五入增量而永久丢失小位移。轮径残差只施加到编码器测量模型/里程计假定几何的差异，不无意更改物理轮胎模型。横向运动保留vy，不设置差速车vy=0伪观测。真实接触滑移由物理模型产生，后续故障注入不和已有滑移重复计算。协方差应基于不同速度、转向和滑移工况的独立误差统计调节；初始数值不视为最终标定。

## 安装外参与标定残差（第二步必做）

用户补充：双GNSS天线、相机支架等安装误差必须进入第二步定位/采集链路验证。当前仅记录设计，尚未实现误差注入。区分实际安装T_true与算法标定T_hat：传感器生成、成像和物理几何使用实际安装，定位、控制、覆盖预测及离线重投影使用标定安装；二者差异才构成外参误差。刚体误差用SE(3)扰动，声明左右乘、坐标系、单位和协方差；不可把欧拉角任意相加后声称完全等价。

- **双GNSS**：包含整个平台相对车体的共同位置/姿态误差，以及两根天线各自的相位中心位置残差。共同平移影响杆臂补偿，共同旋转影响基线相对车头的方向；差分位置误差影响基线长度和方向。标称1.10 m基线不强行锁为真实长度。天线外壳中心与电气相位中心的偏差单独声明。由实际相对基线及算法安装补偿传播航向误差，不能再独立叠加一份重复的固定yaw噪声。
- **相机**：支架相对车体的XYZ及roll/pitch/yaw残差，必要时再区分相机相对支架的残差。高度、俯仰、横滚影响地面投影和有效幅宽，偏航影响扫描线方向；沿程杆臂误差在掉头后改变世界方向。真实安装偏差必须同时进入实际光学射线/相机几何，而不是只给位置标签加噪声。镜头内参残差是另一类误差，不能混成安装偏差。
- **IMU与雷达**：IMU安装旋转影响角速度/加速度到车体的转换，杆臂涉及旋转运动中的加速度；双C8分别记录6自由度外参残差，供点云融合和障碍位置验证。雷达误差需在后续避障验收继续使用。
- **轮组**：轮径残差之外，补充轮组位置/轴距/轮距和转向零位残差；同一实际几何与里程计/控制假定几何的差异只注入一次。

安装误差默认每次装配/试验按固定种子抽取一次，整段轨迹固定；共同支架误差共享同一扰动，不能各传感器独立抽样抹掉相关性。用户明确本轮不考虑支架振动，不加入振动模型/频谱/验收；受力挠曲、温漂也不随固定外参试验隐式启用，以后另行确认时变误差源，不把固定安装残差每帧重抽成白噪声。

试验先做零残差，再单独扫描位置1/3/5 mm和姿态0.05/0.10/0.20°量级，最后组合验证；这些是拟定敏感性试验档位，不是真机制造精度或已确认的随机分布。逐轴有符号固定偏差与跨运行随机样本分别报告，正式正常工况强度待装配/标定资料确认。GNSS角度档位用于共同支架姿态，单天线相位中心主要用位置残差；不要把天线自身绕相位中心旋转直接当作基线旋转。

归档实际安装、标定安装、误差配置、随机种子与标定版本，但真值外参和真值轨迹只进入独立评价档案，不发布到生产TF/位置标签供算法偷用。视觉显示可用单独的真实几何TF。robot_localization不能默认自动估计这些未知外参，增加测量R也不等于消除固定偏差。

验收包含正反扫描、横移、180°换行及后续坡面，报告融合定位/航向偏差、沿横轨跟踪误差、实际扫描足迹与规划差异、侧向重叠/漏扫及条带接缝误差；不能只看EKF轨迹是否平滑。以相机高度约1.046 m为例，小角度0.1°指向残差约对应1.83 mm地面投影偏移（约5像素，仅作量级说明），需要单独测试。

## EKF、初始化与时序

采用robot_localization，局部轮速＋IMU EKF 100 Hz，全局加入GNSS的EKF 50 Hz；从首版就采用三维状态估计与地表约束的控制接口（正式架构不锁死z/roll/pitch），只是当前测试地形为平面。高度是接触约束下的估计/规划变量，底盘不能独立升降；坡面和高差后续单独验收。

全局滤波计划启用`smooth_lagged_data=true`、`history_length=1.0 s`，匹配GNSS迟到消息；输出到当前控制时刻的预测、TF时间戳与回放修正均须测试。该参数处理已知测量时刻的迟到数据，不修复错误时间戳，亦不代替异步队列。详见[官方延迟数据处理参数](https://github.com/cra-ros-pkg/robot_localization/blob/rolling-devel/doc/state_estimation_nodes.rst)。

用户确认真机已有双GNSS天线，初始航向采用有效双天线相对基线解＋安装外参；IMU完成重力方向初始化并提供高频传播。默认不再依赖人工输入yaw或先行驶求方向。单基线不能单独提供全部三轴姿态。最新安装为尾部x=−0.85 m平台、左右1.10 m基线、顶端名义1.20 m；航向10 Hz、延时50 ms＋σ=5 ms抖动。航向协方差从相对基线及外参传播，不固定指定0.20°；GNSS位置共模误差与相对基线噪声分开建模。详见[三维与航向设计](SURFACE_HEADING_STRIP_DESIGN.md)。

初始位置协方差按未知位置设置而非近零；首个有效FIX正常初始化后再执行。EKF过程噪声矩阵在实际接入时按状态顺序、采样周期和创新统计配置，不从传感器噪声数字直接复制。IMU/轮速传感器超时与GNSS质量分别监督：局部反馈过期100 ms触发受控停车；FIX有效测量年龄超过0.5 s进入定位降级，首版停止巡检并保留缺口，不等待漂移到不可控再处理。门限按仿真测量年龄判断；独立通信看门狗用单调墙钟。

## 独立压力场景（默认关闭）

1. GNSS随机丢包1%，以及固定2 s/5 s失锁，验证降级停车、重新定位和补扫。
2. GNSS传输延时150 ms＋σ=20 ms抖动（限制±60 ms），独立测试迟到数据。
3. 测量时间戳偏差+20 ms、σ=2 ms抖动；与传输延时分开，默认关闭。
4. 天线杆臂标定残差[+0.02,-0.01,0] m，随车体旋转，验证掉头后的系统误差。
5. 按通道分别测IMU慢漂、轮径误差增大、真实滑移、RTK FLOAT或位置跳变。异常值不能继续上报FIX的小协方差。

所有源使用独立固定种子，并随任务归档；先测零噪声功能基线，再测正常噪声和单项压力，不一次混入所有异常。报告测量误差、融合误差、横向跟踪、实际有效覆盖、时间戳/延时及连续行号。11 kHz吞吐目标和1.00 m轨迹间距不变；GNSS精度不能替代图像配准精度。
