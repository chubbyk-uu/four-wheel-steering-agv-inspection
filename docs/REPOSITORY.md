# 公开仓库与恢复边界

首次公开为当前可恢复源码的干净快照，不发布早期本地 Git 历史。提交身份使用 GitHub 公开账号和 noreply 邮箱。

上传：四个 ROS 包、构建文件、配置、测试和工具、项目规范、脱敏后的实验摘要、小预览、AI 缺陷原图、外部素材来源及哈希。

不上传：机器专用 AGENTS.md、build/install/log、Python 缓存、环境密钥、代理地址、8K 外部原图与 ZIP、生成图块、原始进程日志、SDK 和驱动库。历史记录中的个人路径替换为示例路径，性能指标保留。公开代码不依赖相邻机器人项目。

基本恢复路径为 README 的克隆、rosdep、colcon 和启动步骤。几何场景由 generate_shared_scene.py 再生；混凝土资产由 fetch_ambient_concrete.py 下载和 bake_concrete_road.py 烘焙；AI 缺陷输入已经在 Git 中，无须重新生图。外部素材的可恢复性仍依赖上游下载可用，下载记录保存摘要。生成结果不是 Git 的二进制备份。

旧候选仅保留小预览和报告。OptiX 的 WSL 驱动兼容性依赖机器，需要新环境验证；不把历史验证结果声明为所有平台保证。公开前已在独立源码目录完成无CUDA构建：四个包构建成功，75项colcon测试通过，机械模型检查通过，4项纹理拼接单测通过。此检查复用了主机已有系统依赖，未声称在全新操作系统安装过驱动或重跑全场GPU性能。

隔离无界面启动检查通过，controller_manager服务确认3个底层控制器处于active，检查结束后已停止实例。基础构建警告包括无关包未使用CUDA开关和既有测试宏的括号提示，未导致失败。本轮没有新做原生Linux GPU验证，也没有重复完整纹理下载/烘焙。
